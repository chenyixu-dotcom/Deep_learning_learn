
# AI Music Generator 🎵

A project where I trained neural networks from scratch to generate music.

I started with a simple character-level LSTM trained on ABC notation, moved to MIDI-based note generation, and eventually built a hierarchical system that plans music at the bar level before generating individual notes.

This repo contains the code, experiments, and different versions of the model.

- **V2** — MIDI-based LSTM for note generation

- **V2.1** — Hierarchical bar-level composer + note generator
